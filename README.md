# Cybersecurity Log Analyzer
A simple Python tool that analyzes login logs and detects suspicious IP addresses and repeated failed login attempts.


## Features 
- reads login logs from a text file 
- detects failed login attempts
- counts failed attempts by IP address
- identifies suspicious IP addresses
- counts failed attempts by usernames

## Technologies
- Python 3
- GIT
- GitHub

## How to Run

Clone the repository:
git clone https://github.com/2007siranush-web/cybersecurity-log-analyzer.git
Go to the project directory:
cd cybersecurity-log-analyzer
Run the analyzer:
python3 analyzer.py

## Example

The analyzer can detect repeated failed login attempts and report suspicious IP addresses.
Example:
SUSPICIOUS IP: 10.0.0.5 - 4 failed attempt
